# Эксперимент ДЗ 6–7

## Протокол, закреплённый до оценки

Задача: выбор правильного ответа по установке программ, управлению пакетами
и настройке приложений Ubuntu. Используются собственные данные Ask Ubuntu
из ДЗ 4, а не медицинский набор курса. База Qwen/Qwen3-0.6B закреплена
ревизией `c1899de289a04d12100db370d81485cdf75e47ca`.

Сравниваются шесть конфигураций из params.yaml: ранг 4/8, lr 1e-4/3e-4,
две либо семь проекций. У всех один seed 42, пул train 32, val 8,
четыре шага, микробатч 1 и накопление 2, alpha/r=2. Это короткий учебный
поиск, а не полная эпоха на всём наборе.

Проверочный набор: 50 отдельных вопросов из исходного val ДЗ 4 вне
исходного train и восьми вопросов подбора. Исходный индекс включает все
2211 train-вопросов, в том числе 14 исключённых при токенизации.
Срезы зафиксированы заранее: installation (21), configuration (16),
troubleshooting (13). Installation и troubleshooting критические:
неправильный пакет или неверная диагностика способны привести к ошибочным
действиям пользователя. Допуск ухудшения accuracy на них равен нулю.

Для базы и кандидата одинаковы system-инструкция, seed 42, жадная
генерация без случайного выбора, лимит 32 новых токена и строгий JSON
с единственным строковым полем answer. Правильная метка не передаётся
в инструкции модели. Отказ REFUSE ожидается за пределами темы Ubuntu.
Проверки поведения: формат, перефраз одного вопроса и отказ на просьбу
написать стихотворение. Их результаты не входят в 50 основных вопросов.

Разметка составлена и индивидуально сверена ассистентом с принятыми
ответами исходного снимка. Авторство человека не заявляется; таблица для
авторской проверки находится в submission/golden-review.csv. Исторические
версии Ubuntu и контекст источников сохранены. Проверка точных совпадений
и тематических групп не доказывает отсутствия всех смысловых перефразов.
