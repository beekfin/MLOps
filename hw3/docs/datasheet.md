# Datasheet: Ask Ubuntu Package Management

## Назначение

Датасет предназначен для обучения ассистента, который отвечает на вопросы об
установке программ и управлении пакетами в Ubuntu. Каждый пример содержит
системную инструкцию, вопрос пользователя и принятый сообществом ответ.

## Источник и лицензия

Источник — вопросы и принятые ответы Ask Ubuntu по тегам `apt`, `dpkg`, `snap`,
`software-installation` и `package-management`. Зафиксированный снимок получен
через Stack Exchange API. Полная выгрузка Ask Ubuntu доступна по прямой ссылке:
https://archive.org/download/stackexchange/askubuntu.com.7z.

Публикации Stack Exchange распространяются по CC BY-SA: версия лицензии зависит
от даты публикации. Идентификатор `askubuntu-N` соответствует странице
`https://askubuntu.com/questions/N`, поэтому происхождение примера можно
восстановить. Условия лицензирования:
https://stackoverflow.com/help/licensing.

## Преобразование источника

Исходный снимок содержит 4841 пару «вопрос — принятый ответ». Стадия `collect`:

1. детерминированно выбирает строки по SHA-1 от идентификатора, поэтому `v1`
   является подмножеством `v2`;
2. преобразует HTML вопроса и ответа в обычный текст;
3. назначает тематическую группу по наиболее конкретному тегу вопроса;
4. детерминированно выбирает одну из пяти системных инструкций.

Очистка выполняется в порядке: проверка схемы, фильтр длины, маскирование ПДн,
точная дедупликация, near-duplicate дедупликация.

## Распределение длин v2

Длина измеряется в символах после очистки.

| Поле | p10 | p50 | p90 | p99 | max |
|---|---:|---:|---:|---:|---:|
| Вопрос пользователя | — | 653 | 2115 | 3573 | 4000 |
| Ответ ассистента | 175 | 557 | 1853 | 4835 | 24197 |

Отношение p90/p10 для ответов равно 10,59. Доля самой частой длины ответа —
0,33%, доля повторяющихся ответов — 0,07%. Крупнейшая тематическая группа
занимает 5,07% набора.

## Разбиение v2

Разбиение выполняется целыми тематическими группами с seed 42.

| Сплит | Примеров | Групп | Доля |
|---|---:|---:|---:|
| train | 2211 | 378 | 80,02% |
| val | 276 | 202 | 9,99% |
| test | 276 | 203 | 9,99% |

Между train и test нет пересечений по идентификаторам, нормализованному тексту,
тематическим группам и near-duplicate парам.

## Ограничения

- Данные отражают англоязычные вопросы Ask Ubuntu и не предназначены для
  поддержки других операционных систем.
- Принятый ответ может устареть вместе с версиями Ubuntu, APT или Snap.
- Принятие ответа автором вопроса не гарантирует, что это единственное или
  лучшее решение.
- Фильтр удаляет вопросы длиннее 4000 символов, поэтому сложные случаи могут
  быть представлены слабее.
- Автоматическое преобразование HTML может упростить исходное форматирование
  команд и фрагментов кода.
