# ДЗ 2 — анатомия модели

Готовый разбор модели: параметры, активации, LoRA и память.
Имя модели и условия запуска задаются в `params.yaml`.

## Запуск

Из папки `hw2`:

```bash
uv sync --locked
make inspect
make check
uv run python -m unittest discover -s tests -v
```

`make inspect` выполняет каждый режим памяти в отдельном процессе, затем
сохраняет отчёт и график. На этом ноутбуке используется CPU.
Повторный запуск обновит Markdown и JSON, но не заполненную Excel-таблицу:
её числа соответствуют сохранённому запуску и должны обновляться вместе с ним.

## Результаты

- `docs/anatomy.md` — условия, таблицы, формулы и разбор четырёх дефектов.
- `docs/report.json` — исходные числа, формы всех параметров, нормы и PID замеров.
- `docs/activations.png` — график норм трёх слоёв.
- `docs/anatomy-worksheet.xlsx` — заполненная таблица с работающими формулами.
- `docs/check.txt` — вывод успешной самопроверки.
- `docs/check.cast` — запись настоящего PTY-сеанса с временными отметками.
- `docs/check.mp4` — видео этой записи: весь терминал, исходный порядок и время вывода.

Видео построено из записанного вывода реального `make check`, без изменения
результатов. Это воспроизведение терминальной записи, а не съёмка рабочего стола.

В исходном Excel-шаблоне для нормализаций была одна строка, хотя размеры
векторов разные. На листе «Параметры» добавлена расшифровка 56 × 128 и
57 × 1024; она входит в общий итог только один раз. Для общего `lm_head`
исключён повторный учёт весов. На листе «LoRA» ниже первого добавлен второй
конфиг. Все пять исходных листов сохранены. Формулы проверены пересчётом,
в том числе в LibreOffice; неверные входные числа вызывают ошибки проверок.

## Исправления

1. Общие веса учитываются по уникальному объекту параметра.
2. Хуки снимаются через `finally`, даже если forward завершился ошибкой.
3. Для каждого режима и повтора запускается отдельный Python-процесс.
   Память отслеживается во время вычислений, начиная с загрузки модели.
4. Метрика соответствует устройству: RSS на CPU, пик аллокатора CUDA,
   максимум выборок памяти драйвера MPS.

Восемь дополнительных тестов проверяют общие и раздельные веса,
снятие хуков при исключении, формулу LoRA, изоляцию процессов и метрики памяти.
CUDA/MPS проверены с подставными API-значениями; реальные замеры — на CPU.

## Проверка чисел

Уникальных параметров: 596 049 920. LoRA: 1 146 880 и 10 092 544,
оба значения точно совпали с PEFT.

Пики из `make inspect`: инференс 2525,6 МиБ, полное дообучение 6809,3 МиБ,
LoRA 3291,1 МиБ. Самопроверка делает новые замеры; небольшое отличие от
отчёта ожидаемо. В записи проверки пики составили 2526, 6868 и 3290 МиБ
после округления.

Тема датасета относится к следующей работе и здесь не изменялась.
